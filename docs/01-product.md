# 01. 제품 정의 — MVP 범위와 용어

이 문서는 AI 협업 웹소설 집필 플랫폼의 MVP가 **무엇을 하고 무엇을 하지 않는지**, 그리고 모든 역할이 같은 뜻으로 써야 하는 **용어**를 정리한다. 결정 원본은 `.forge/agenda.md`의 "결정됨" 목록과 `.forge/CONTEXT.md`이며, 이 문서는 그 내용을 제작용으로 옮긴 것이다.

## 목적지

작게 시작할 MVP의 범위·기술 스택·데이터 모델·AI 협업 방식을 정해, 각 역할(frontend·backend·story·imagery·qa·deploy)이 첫 빌드 작업에 착수할 수 있게 하는 것이 이 문서 묶음의 목적이다. 제품 자체의 목표는 **작가가 설정과 컨셉을 정리하고, 그 설정을 근거로 AI와 함께 일관성 있는 글과 이미지를 만드는 집필 도구**다.

## 누가 쓰는가

### 작가 1명 + AI 협업

"사람과 같이 쓴다"는 **작가 1명 + AI 협업**을 뜻한다. 한 작품의 작가는 한 명이며, 여러 사람이 한 작품을 함께 쓰는 공동 집필은 MVP에서 하지 않는다. 따라서 실시간 동시 편집, 작품 단위 권한 공유, 편집 잠금 같은 기능은 만들지 않는다.

### 초대받은 소수 작가

서비스에는 **초대받은 소수 작가**만 가입한다. 각 작가는 자기 계정으로 로그인해 **자기 작품만** 보고 다룬다. 가입은 관리자가 발급한 초대 코드로만 가능하고, 공개 가입은 없다. 로그인 방식과 초대 흐름은 [02 아키텍처의 인증 절](02-architecture.md#인증과-초대)에 있다.

## MVP에 들어가는 AI 기능

MVP 첫 빌드에는 아래 AI 기능이 **모두** 들어간다.

| 분류 | 기능 | 자세한 동작 |
|---|---|---|
| 텍스트 집필 보조 | 이어쓰기, 선택 영역 다시쓰기, 문체 다듬기 | [04 스토리 엔진](04-story-engine.md), [06 에디터](06-editor-and-ai-ux.md) |
| 구상과 초안 | 줄거리 구상, 회차 초안 | [04 스토리 엔진](04-story-engine.md) |
| 이미지 | 캐릭터·장소·소품 설정의 이미지 생성(장소를 그린 이미지를 "배경"이라 부른다) | [05 이미지 엔진](05-image-engine.md) |
| 자료 조사 | 웹 검색 기반 질의응답과 자료 저장 | [07 자료 조사](07-research.md) |

에디터 안에서 이 기능을 부르는 방식(선택 영역 메뉴, "/" 명령, 사이드 AI 패널, ghost text)은 [06 에디터와 AI 협업 UX](06-editor-and-ai-ux.md)에 있다.

## 용어

모든 문서·코드·화면 문구는 아래 용어를 쓴다. 정의는 `.forge/CONTEXT.md`와 같고, "피할 말"은 같은 개념에 쓰지 않는 단어다.

| 용어 | 정의 | 피할 말 |
|---|---|---|
| 작가 | 초대 코드로 가입해 자기 작품을 AI와 함께 쓰는 사람. 한 작품의 작가는 한 명이다. | 사용자, 유저, 공동 작가 |
| 작품 | 한 작가가 소유하는 웹소설 한 편. 회차와 설정을 담는다. | 소설, 프로젝트 |
| 회차 | 작품을 이루는 연재 단위의 본문 한 편. | 챕터, 에피소드 |
| 컨셉 | 작품 전체에 항상 적용되는 작품 속성(장르, 톤, 서술 시점, 화풍 프리셋, 타깃 독자). 설정이 아니다. | 기획서, 작품 설정 |
| 화풍 프리셋 | 한 작품의 모든 이미지가 같은 그림체로 나오도록 컨셉에 지정하는 이미지 그림체 지정. | 스타일, 테마 |
| 설정 | 작품 속 캐릭터·장소·소품·세계관 중 하나를 정의한 문서. 정형 필드와 설정 본문으로 이루어진다. | 로어북, 위키, 설정집 |
| 캐릭터 | 작품에 등장하는 인물을 정의한 설정. | 인물, 등장인물 |
| 장소 | 작품의 무대가 되는 공간을 정의한 설정. "배경"은 장소를 그린 이미지를 말할 때만 쓴다. | 로케이션 |
| 소품 | 작품에 등장하는 사물을 정의한 설정. 소유한 캐릭터를 가질 수 있다. | 아이템, 오브젝트 |
| 세계관 | 작품 세계의 규칙·역사·체계를 정의한 설정. 이미지를 갖지 않는다. | 월드, 세계 설정 |
| 정형 필드 | AI가 이미지 생성과 설정 충돌 검사에 그대로 사용하는, 설정의 구조화된 핵심 값(이름, 외형 키워드, 상태 등). | 메타데이터 |
| 설정 본문 | 설정 중 정형 필드에 담기지 않는 서술을 블록 에디터로 자유롭게 쓴 부분. | 메모, 설명 |
| AI 제안 | AI가 만든 본문 변경 후보. 작가가 수락하기 전까지 본문에 반영되지 않는다. | 자동 수정, AI 편집 |
| 회차 스냅샷 | 특정 시점의 회차 본문 전체를 보존한 사본. 작가는 이 시점으로 회차를 되돌릴 수 있다. | 리비전 |
| 고정 설정 | 본문에 언급되지 않아도 해당 회차를 쓸 때 AI가 항상 참고하도록 작가가 회차에 지정한 설정. | 핀, 즐겨찾기 설정 |
| 설정 점검 | 작가가 요청하면 AI가 회차 본문을 설정과 대조해 모순과 필드·본문 불일치를 찾아 주는 검사. | 검수, 교정, 팩트체크 |
| 회차 요약 | 작가가 회차를 완료로 표시할 때 AI가 만들고 작가가 고칠 수 있는 회차 내용의 요약. 오래된 회차를 AI에 전달할 때 전문 대신 쓴다. | 요약본 |
| 시놉시스 | 작품 전체의 큰 줄거리와 결말 방향을 담은 작품 단위 문서. AI가 글을 쓸 때 항상 참고한다. | 개요, 줄거리 문서 |
| 플롯 메모 | 한 회차에서 일어날 일을 적은 짧은 메모. 회차 본문과 별개이며, 그 회차를 쓸 때만 AI가 참고한다. | 콘티, 회차 계획, 아웃라인 |
| 자료 | 작가가 자료 조사 결과 중 저장하기로 한 것. 요약과 출처(URL·짧은 인용)로 이루어지며 웹 원문은 담지 않는다. | 리서치, 스크랩 |
| 대표 이미지 | 작가가 승인한 캐릭터·장소·소품의 기준 이미지. 같은 대상의 모든 이미지 생성에 참조 입력으로 들어간다. | 썸네일, 프로필 이미지 |

## 범위 밖

아래 항목은 MVP에서 의식적으로 제외했다. MVP 범위 안에서는 다시 열지 않는다.

| 항목 | 제외 이유 |
|---|---|
| 결제·요금제 | MVP 첫 빌드 착수와 무관하다. AI 비용은 운영자가 부담한다. |
| 독자용 연재 공개·댓글·구독 | 목적지는 집필 도구다. 독자 화면이 필요해지면 별도 앱으로 붙인다. |
| DBMS 실제 이전 작업 | MVP에서는 PostgreSQL 등으로 옮길 수 있는 설계([03 데이터 모델](03-data-model.md#db-접근층과-이식성-규칙))만 지키고, 이전 실행은 이후 일이다. |
| 모바일 네이티브 앱 | 웹으로 시작한다. |
| 여러 작가의 공동 집필·실시간 동시 편집(CRDT 등) | MVP는 작가 1명 + AI 협업으로 정했다. |

## 아직 흐림

아래 항목은 범위 안에 있지만, 아직 질문으로 다듬을 수 없을 만큼 흐릿하다. 앞선 결정의 결과를 보고 다시 판단한다.

- **회차 시점별 설정 값** — 회귀·회상 장르에서 "몇 회차 기준" 외형·상태가 필요할 수 있다. MVP는 정형 필드의 현재 값만 둔다. 과거 회차를 퇴고할 때 생기는 잘못된 경고가 실제로 얼마나 거슬리는지 보고 판단한다.
- **장면 삽화** — 캐릭터·장소·소품을 한 장면으로 합성하는 이미지. 개별 이미지 일관성 방식이 실제로 동작한 뒤에 다룬다.
- **외부 연재 플랫폼용 내보내기 형식**.
- **프롬프트 템플릿·출력 스키마 버전 관리의 구체 방식** — story 엔진 구조가 정해진 뒤 다룬다.
- **장편 일관성 평가(eval)** — 설정 주입 방식이 실제로 동작한 뒤 측정 방법을 정한다.
- **캐릭터별 LoRA** — 호스팅 모델 은퇴로 그림체가 바뀌는 문제가 실제로 생기거나, 자주 쓰이는 캐릭터의 고정력이 부족할 때 다룬다.
